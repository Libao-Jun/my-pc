# Claude Code 行为规则

## 代码生成规则

### TypeScript/React 规则
- 使用函数组件和Hooks
- Props必须定义接口
- 使用项目的状态管理方案
- 遵循项目的文件命名规范

### 后端规则（Node.js）
- 使用控制器-服务-路由分层架构
- 所有接口必须有参数验证
- 错误处理必须使用统一错误类
- 数据库操作必须使用ORM查询构建器

## 交互规则
1. 复杂功能先输出设计方案
2. 关键决策需要用户确认
3. 修改前说明影响范围
4. 代码生成后提供说明

## 质量要求
- TypeScript严格模式
- 无any类型（除非必要）
- 完整的错误处理
- 必要的注释
