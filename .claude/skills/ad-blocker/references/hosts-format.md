# hosts 语法与常见广告域名

## 语法

```
# 注释
127.0.0.1  ad.example.com
0.0.0.0    ad.example.com
```

- 每行：`<IP> <域名>`，IP 与域名间用空格或 Tab 分隔。
- `127.0.0.1` 解析到本机回环（个别软件会跳过）；`0.0.0.0` 更彻底（直接不可达，推荐用于广告）。
- `#` 开头为注释。
- 一个 IP 可跟多个域名（空格分隔），但建议一行一个域名，便于增删与回滚。

## 常见广告 / 推荐域名示例（可按软件归类维护）

- 通用广告：`*.doubleclick.net`、`*.googlesyndication.com`、`*.adservice.google.com`、`*.adsrvr.org`
- 输入法弹窗 / 推荐：`*.sogou.com`、`*.sogoucdn.com`，以及 `*.baidu.com` 中的广告子域（需按具体软件排查后维护精确域名，避免误伤正常功能）
- 视频播放器：各厂商的 `*.ad.*` / `*.ads.*` 子域

> 注意：域名清单需持续维护，且要精确到「广告子域」，避免把整站主域名屏蔽导致软件核心功能不可用。
