# 广告与个性化推荐屏蔽

通过 **hosts 文件**把广告 / 推荐域名解析到 `127.0.0.1`（或 `0.0.0.0`），让请求无法到达真实服务器，达到屏蔽效果。适用于浏览器、视频播放器、搜狗 / 百度输入法等的弹窗与个性化推荐。

## hosts 文件

- Windows 路径：`C:\Windows\System32\drivers\etc\hosts`
- 语法与通用域名示例见 `references/hosts-format.md`。

## 关键约定

- **管理员权限**：修改系统 hosts 需要管理员权限。Electron 端提权重启，或引导用户「以管理员身份运行」；写入失败（`EACCES`）时给出明确提示。
- **备份 / 回滚**：每次修改前先把原 hosts 复制为带时间戳的备份（如 `hosts.bak.20260818`），提供「一键恢复」能力。
- **幂等写入**：追加规则前先检查目标域名是否已存在，避免重复行。
- **按软件分类**：把屏蔽规则组织为「软件 → 域名列表」，用户可单独开关某个软件的屏蔽，而不是全局无差别。
- **解析与刷新**：改完 hosts 后提示用户刷新 DNS 缓存（`ipconfig /flushdns`），否则可能不立即生效。

## 屏蔽策略

1. 读取要屏蔽的软件列表与其广告域名（内置一份常见清单，允许用户增删）。
2. 拼接 `127.0.0.1 <domain>` 行，写入 hosts。
3. 支持「仅屏蔽广告」与「同时屏蔽个性化推荐」两档，推荐域名单独归类。
4. 记录操作日志（写入哪些域名、何时、可回滚）。

> 说明：只做本机 hosts 层面的域名拦截，不涉及注入、篡改软件二进制或规避安全软件。
