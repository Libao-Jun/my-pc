# STAR 简历字段模板

## 技能（Skills）

- 名称 / 熟练度（如：掌握 / 熟练 / 精通）
- 相关年限
- 一句可验证的说明（在哪个项目 / 场景用过）

## 工作经历（Experience）

- 公司 / 职位 / 起止时间
- 一句话职责概述
- 2–4 条 STAR 条目，每条：情境 + 任务 → 行动 → 结果（尽量带数字）

## 项目经历（Projects）

- 项目名 / 角色 / 起止时间
- 一句话项目背景（情境 + 任务）
- 3–5 条「行动 → 结果」，突出本人贡献与量化产出
- 技术栈标签

## 量化结果常用角度

性能提升 %、响应时间、用户量 / 访问量、成本下降、交付周期缩短、覆盖规模（接口数 / 页面数 / 团队人数）。
