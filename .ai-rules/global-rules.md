# AI Agent 全局开发规则

## 项目信息
- 项目名称：my-pc
- 技术栈：Electron, React, Node.js, TypeScript, SQLite
- 项目类型：桌面应用

## 核心原则
1. 所有代码必须遵循项目编码规范
2. 每次修改前必须检查现有代码结构和模式
3. 新功能开发必须包含类型定义、错误处理和测试
4. 保持代码一致性，遵循现有模式
5. 优先使用项目中已存在的工具库和组件

## 开发流程要求
1. 理解需求：先分析现有代码结构
2. 设计方案：提供实现方案供确认
3. 编写代码：按照规范编码
4. 自检：检查代码质量
5. 文档：更新相关文档

## 禁止行为
- 不生成未要求的功能
- 不修改不相关的文件
- 不跳过类型检查
- 不使用项目中未包含的依赖
